# Security policy

Report authentication bypasses, replay, credential disclosure, cryptographic issues, and unsafe defaults privately. Use [GitHub private vulnerability reporting](https://github.com/bridge-applications/tg-auth-public/security/advisories/new) when available. If private reporting is unavailable, contact the maintainer through the contact information on the [GitHub profile](https://github.com/tspunt). Do not publish working exploits or credentials in a public issue.

Include package/runtime versions, affected configuration with secrets removed, synthetic reproduction steps, expected and actual behavior, and impact. Never submit real user identities or bearer credentials.

The current public development line is 2.0. Internal 1.x consumers need coordinated review and migration. Before disclosing an issue shared with private deployments, coordinate remediation with the maintainer. This project does not claim an independent security audit.
